J'ai une question -> tengo una pregunta
Je ne sais pas -> no sé
	Je'n sais pas -> reducción[^1] (no se escribe -en contraste con las contracciones-)
	sais pas -> abreviación
Je ne comprends pas -> no entiendo
	Je'n comprends pas
	Je n'ai pas compris -> no entendí
==Je voudrais== -> Yo quisiera (pedir educadamente)
	Je voudrais poser une question -> puedo hacer una pregunta
C'est quel exercice? -> ¿Qué ejercicio es?
Vous pouvez expliquer encore une fois, s'il vous plait? -> ¿Puedes explicarme una vez más?, por favor
encore une fois, s'il vous plaît? -> ¿una vez más?, por favor
Comment on puet dire \_\_\_\_ en français? -> ¿Cómo se dice 'x' en francés? (el 'ent')
Qu'est-ce que ça veut dire -> Qué significa eso? (el -ce no se pronuncia)
Comment ça s'écrit? -> cómo se escribe
Vous pouvez épeler? -> ¿Puede deletrearlo?
==Je peux== -> Base del pedir
C'est fini -> terminé
Qu'est-ce qu'il faut faire? -> ¿Qué hay que hacer?
Vous pouvez répéter, s'il vous plaît?
Vous pouvez parler plus lentement? -> ¿Puede hablar más despacio?
ça s'écrit comment?
J'ai oublié -> Lo olvidé
J'ai oublié mes devoirs -> olvide mi tarea
Je peux sortir? -> ¿Puedo salir?
	Est-ce que je peux sortir? -> más formal
Est-ce que je peux aller aux toilettes? -> ¿Puedo ir al baño?
