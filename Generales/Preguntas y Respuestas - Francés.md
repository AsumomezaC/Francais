# Preguntas (Les Questions)
## Auxiliar
Para [[#Questions Fermées (cerradas)]] y [[#Questions Ouvertes (abiertas)]] puedes acompañarlas con el auxiliar para formalidad "est-ce que".
Ej.
- Qu'est-ce que...
- Est-ce que...
## Questions Fermées (cerradas)
**Respuestas**: Oui, Non, Si -negar negación-

> [!important] IMPORTANTE: Poner la entonación de pregunta.

>Con esto es suficiente para hacer la pregunta, pero si la quieres hacer formal:
### Formal
Se agrega el auxiliar Est-ce que (se pronuncia 'es que'):
Est-ce que + phrase + ?
>Si la frase empieza con vocal, el que se abrevia a qu'
### Inversion Sujet/Verbe
**Muy Formal:** Solo usada en lenguaje escrito, ej:
>Tu fais les courses -> Fais-tu les courses? (sin coherencia pq no se puede ser formal con tu) -> Faites-vous les courses?
## Questions Ouvertes (abiertas)
Respuestas completas.
### Palabras interrogativas
Porquoi -> por qué
> [!warning] Esta nunca va al final

Où -> Dónde
Quand -> Cuándo
Que/Quoi -> Qué (que -> formal\[va siempre al inicio -se apoya del auxiliar-], quoi -> informal\[va después del verbo])
	>Si el Que esta pegado con una palabra que inicia en vocal se reduce a Qu'
	>Sirven para omitir el 'Qu'est-ce que' (nunca hacen la liasen). Se cambia el orden, al final va sujeto + verbo.
	>Para preguntar por 'Qué' de 'Cuál'
	>- Quel -> masculino, singular
	>- Quelle -> femenino, s
	>- Quels -> m, plural
	>- Quelles -> f, s
Comment -> Cómo
### Forma familiar
Frase + palabra interrogativa.
ej.
	Tu pars oú?
### Forma formal
>Si se refiere de usted

Palabra interrogativa + est-ce que + phrase + ?
ej.
	Où est-ce que tu pars?
# Respuestas
## Porque
Parce que, car, pour -> porque
>- Parce/car: Seguida de una oración completa
>- Pour: seguida de un verbo o un sujeto
