# Verbos -er
Se quita la parte de 'er', y se adjunta:
- je/j' -> +e
- tu/t' -> +es
- il/elle/on ->  +e
- ils/elles -> +ent
- nous -> +ons
- vous -> +ez
>El 'on' es el nosotros informal hablado, así como el pronombre en oraciones equivalentes al 'se' en 'se habla francés'

# Verbo pronominales
>Son aquellos que se acompañan de un pronombre
>>Como llamar, nosotros no decimos 'Yo llamó X', se dice 'Yo ==me== llamó'
>>Se usa para un verbo que se puede aplicar para otra persona o para el sujeto de la acción

Se conjugan igual que los [[#Verbos -er]]
appeller -> llamar
promener -> pasear
	si se usa como sustantivo se usa 'faire une pomenade'
doucher -> bañarse
visiter -> visitar
	
> [!NOTE] Pronombre
> me -> 'je'
> se -> 'il/elle/on'
> te -> 'tu'
> se -> 'ils/elles'
> nous -> 'nous'
> vous -> 'vous'
> vous -> 'vous (usted)'
> >Si algún verbo empieza con vocal se realiza una contracción (s', m', t') o se hace la liaison.
> >Ojo: se repite la forma del ==pronombre==

# Verbos del tercer grupo
Son aquellos que no pertenecen ni al primer ni al segundo [[#Grupos]], pero hay más de dos verbos que se conjugan igual (a diferencia de los [[#Irregulares]]).
### Descendre
>Descender / Bajar
>
- je -> descends 
- tu/t' -> descends
- il/elle/on ->  descend
- nous -> descendons
- vous -> descendez
- - ils/elles -> descendent
### Prendre
>Tomar
- je -> prends 
- tu/t' -> prends
- il/elle/on ->  prend
- nous -> prenons
- vous -> prenez
- - ils/elles -> prennent
# Irregulares
>Irréguliers
## être
>Ser o estar
>	para nacionalidad, localiser, adjectifs, présenter (con c'est)
- je -> suis
- tu -> es
>No se hace nunca la liaison de 's'
- il/elle/on/c' ->  est
- ils/elles -> sont
- nous -> sommes
>No se pronuncia la 'mes'
- vous -> êtes
## Avoir
>Tener
>	para edad, para posesión (incluye familia)
- j' -> ai
- tu/t' -> as
- il/elle/on ->  a
- ils/elles -> ont
- nous -> avons
- vous -> avez

> [!important] Il y a
> Muy utilizado, y significa 'hay'
> >Negación: Il n'y a pas
