chez -> con (referente a posición o pertenencia -de objetos-)
>chez-moi -> (se refiere a mi casa), la preposición puede cambiar según la necesidad
>	ej. chez-toi

avec -> con
>Se refiere a acompañamiento, nótese que en español no se diferencia con el 'chez'
>ej. voy con el panadero (a la panadería) o voy con el panadero (acompañado) no son iguales

## Preposiciones de lugar
à côté -> a un lado
en face -> en frente
loin -> lejos
près -> cerca
>como en español siempre se agrega 'de', ej. cerca ==de== == près de..

>> este no incluir el 'de' al escribir

dans -> dentro
sur -> sobre de 
sous -> abajo 
entre -> entre
devant -> delante
vers -> hacia
### Tipos de 'de'
du -> de + le
de la -> de + la
de l' -> de + l' -si empieza con vocal y no es plural-
des -> de + les -se pronuncia la 'e' como el español-
### Tipos de 'al', 'a la', 'a los'
au -> à + le (masculino)
à la -> femenino
à l' -> inicia con vocal
aux -> para plurales
## en / à
>Moverse a través de

en -> cuando el medio de transporte es cerrado
à -> cuando el medio de transporte es abierto
