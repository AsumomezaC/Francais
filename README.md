Si eres nuevo en obsidian, hay algunas cosas que pueden ser tediosas de aprender y los videos usualmente no muestran. Este repositorio incluye información que estos videos no muestran.

Actualmente cuenta con información de:
- Como poner algunos símbolos matemáticos
- Como sincronizar y automatizar tus apuntes con GitHub utilizando Android -permitiendo interacción entre Laptop/PC y tu dispositivo Android portatil-
