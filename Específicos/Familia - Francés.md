#Francés 
## De sangre
- (f) famille -> familia
- les parents -> los padres
	- [[Adjetivos - Francés#Adjetivos Posesivos|mes]] parents
	- [[Adjetivos - Francés#Adjetivos Posesivos|mon]] père -> padre
		- papa -> papá
	- [[Adjetivos - Francés#Adjetivos Posesivos|ma]] mère -> madre
		- maman -> mamá
- les grands-parents -> los abuelos
	- grand-père / grand mère
		- papy -> abuelito / mamie -> abuelita
- enfants -> si se usa [[Adjetivos - Francés#Adjetivos Posesivos|adjetivos posesivos]] suele ser hijo
	- mon fils -> mi hijo (se escribe igual en plural, pero cambia el posesivo) -==la 'l' es muda==-
	- ma fille -> mi hija
- frère -> hermano
- soeur -> hermana
- oncle -> tío
	- tonton -> forma cariñosa
- tante -> tía
	- tata -> forma cariñosa
- cousin -> primo
- cousine -> prima
- petits enfants -> nietos
	- petit fils -> nieto
	- petite fille -> nieta
### Extras
fils unique -> hijo único
premier-né -> primogénito
	primer-née -> primogénita
paternal -> paterno
maternal -> materno
mari -> marido
#### Famille recomposée
beau père -> padrastro
belle mère -> madrastra
beau fils -> hijastro
belle fille -> hijastra
demi-frère -> medio hermano
demi-soeur -> media hermana
## Política
la belle-famille -> familia de ley

> [!NOTE] Volver a familia política
> Para volverlo política, se agrega esto antes de la palabra: 'beau-' / 'belle-' / 'beaux-'

(m) gendre -> yerno
(f) bru -> noera
