#Francés 
## Abreviación
dispos -> disponible
À plus -> hasta luego
foot -> football
appart -> appartement
resto -> restaurant
fac -> faculté
## Barrio
potes/pote -> amigos/amigo
ça marche -> jalo/juega/se hace/de acuerdo
on fête ça -> lo celebramos
Bises -> besos! -como despedida- (formal: bisous)
À très vite -> hasta pronto
boulot -> chamba
Il caille -> hace frío
Être crevé/crevée -> estar muy cansado (crevé -> muy cansado, -épuisé: cansado, fatigué: cansado-)
Avoir la flemme -> tener flojera 
Être chiant/chiante -> fastidiosa/desesperante (agaçante ou pénible), tmb para situaciones (c'est chiant).
C'est ouf! -> esta situación esta muy loca (c'est fou!)
	pas ouf! -> no esta chido
ça craint -> apesta/peligroso/aburrido
ça me soûle -> una situación irritante/molesta -estándar: ça m'énerve-
Être à la bourre -> ir/llegar tarde (estándar. je suis -très- en retard)
Avoir la dalle -> estar 'starving' (estándar. j'ai faim.)
Être chaud/chaude -> estar motivado para hacer algo/entusiasmado (tiene connotaciones románticas y sexuales).
Se barrer -> irse rápidamente
## Anglicismo
top -> increíble
OK -> ok
