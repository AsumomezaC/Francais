## Pronunciación
>La mayoría de las últimas consonantes no suenan
>Si una 'e' al final de la palabra no esta acentuada no se pronuncia
>Las palabras suelen ser agudas
#### Grafema
ll -> como 'l' mexicana o como 'ill'
e, es -> si esta al final de la palabra no suena al menos que sea un anglicismo
ent -> si termina así un verbo nunca suena
er -> si esta al final de la palabra la 'r' nunca suena
ai -> e -'e' española-
>	No aplicable para algunos nombres propios -como Hawái-

ei -> e -'e' española-
s -entre vocales -> 's' -> suena como z
ss -> 'ss' suena débil
ou -> u -española-
	fourmi -> hormiga
oi -> ua -española-
	étoile -> estrella
eu -> o -española-
>Excepciones: se pronunica como 'u': bleu, pleuvoir

au -> o -española-
oe -> o -española-
##### Vocales nasales
>Se pronuncian como si te faltará aire

an, in, un, im -> an -sonido nasal -
> Si el grafema esta al final de la palabra no suena
> El 'un' solo se pronuncia así en la palabra 'uno'
	imperméable -> impermeable

	brun -> marrón

en, on -> on nasal, con la 'e' suena ligeramente a 'e'
	bonbon -> dulce
>La 'n' no se pronuncia si esta al final de la palabra

om -> om nasal
	pompier -> bombero

am, em -> am -sonido nasal-

et -> si va al final de la palabra no se pronuncia la 't'
ez -> no se pronuncia la 'z' si va al final de la palabra
	nez -> nariz

gn -> ñ
	champignon -> champiñón
ph -> f
	phare -> faro
ein -> an -nasal-
	peinture -> pintura
ien -> ia -primera española segunda nasal-
	magicien -> mago
ier ->ie
	cahier -> cuaderno
ill -> i con ligero sondio de y
	papillon -> mariposa
oeu -> e+o -ya sea con e u o como predominante-
	coeur  -> corazón
oin -> ua -nasal-
	poing -> puño
elle -> ele
	coccinelle -> Catarina
ette ->ete
	noisette -> nuez
esse -> es
	princesse -> princesa
erre -> er -r francesa-
	parterre -> pastel
euil -> eil -e nasal, el resto español-
	feuille -> hoja de árbol
ille -> il o il -con sonido ligero de 'y'-

uin -> u francesa + an nasal
##### Terminaciones
- si termina en '-tiente' la primera 't' suena como 's'

### Presentación
- Je m'appelle..., et toi?
- Je m'appelle..., et vous?
>Usualmente no se pregunta como te llamas, en ocasiones informales solo te presentas y esperas de forma indirecta que el te diga su nombre.


> [!NOTE] Presentación básica
> Bonjour les amis! -> Expresión como Hi guys!
> Je suis Adrián -> Decir nombre
> >Otros datos importantes si gustas
> >- Edad
> >- Ocupación actual
> >- Etc.

#### Pedir nombre
- Comment tu t'appelles?
- Comment vous vous appelez?
### Útiles
Et tois? -> y tú?
Et vous? -> y usted?

pas encore -> no todavía

voici -> aquí (como el 'here' del inglés)
## Modales

	s'il te plait -> por favor

	Merci beaucoup -> muchas gracias
	Merci bien -> muchas gracias
	Merci beaucoup à vous -> gracias a ud
De rien -> de nada

Excusez-moi -> disculpe
	Excuse-moi -> disculpa

Désolé -> Lo siento

c'est dommage -> es una lástima

## Artículos
- Le -> artículo masculino (sonido nasal)
- La -> artículo femenino
- L' -> artículo para palabras que empiecen con vocal
- Les -> artículo en plural (sonido abierto -español-)

---
## Pronombre
ça -> eso
je/j' -> yo
>si sigue un [[Verbos-francés|verbo]] que inicia con sonido vocal se usa j', de lo contrario se usa je

elle -> ella
il -> él
tu -> tú
on -> nosotros -más oral-
> este se puede contraer a t' en el francés hablado informal -como el je-

nous -> nosotros
>se suele pronunciar como 'on' nasal, y se conjuga como il/elle

vouz -> Usted / Ustedes

illes / elles -> ellos / ellas

# Tips
Ce -> es equivalente al 'it's' en inglés
Oui -> lo pronuncian como 'ue' ('ouais' en francés)
c'est ça -> así es
>	plural de c'est -> ce sont

Si se hace una liaison entre una palabra que empieza con 's' y otra que termina con 's' se funcionan en una sola 's'
## Muletillas
- Alors -> bueno
## C'est/ Ce sont... vs Il/elle est... Ils / Elles sont...
### C'est/ Ce sont
C'est/ Ce sont -> se usan cuando lo que sigue tiene sustantivo + complemento
			-> se usa cuando ya se sabe de que se habla pero no se quiero usar el sustantivo
>Similar a cuando omitimos el artículo en español
### Il/elle est... Ils / Elles sont...
Il/elle est... Ils / Elles sont... -> se usa cuando se omite el pronombre
